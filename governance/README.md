# Governance

Working drafts that feed the [DTAC self-assessment](../docs/united-kingdom/national-health-service/digital-technology-assessment-criteria/2.0/index.md). **Every document here is a DRAFT written from the code and the specification. None has been reviewed or approved by a Data Protection Officer, a Clinical Safety Officer, a lawyer or a clinician.** They exist so those people start from the facts instead of a blank page. Do not present them as approved.
